Prácticas

Durante el curso se realizarán prácticas enfocadas en comprender tanto la estructura interna como el funcionamiento de los algoritmos.

En general, los ejercicios podrán incluir:

Construcción de estructuras de datos
Inserción de elementos
Eliminación de elementos
Búsqueda
Recorridos
Balanceo
Análisis del funcionamiento paso a paso
Uso de estructuras auxiliares como pilas y colas
Resolución de problemas utilizando árboles

Se busca evitar utilizar implementaciones completamente automáticas cuando el objetivo de la práctica sea comprender el funcionamiento interno de la estructura.

Objetivo

Al finalizar el curso, el estudiante deberá ser capaz de:

Comprender la representación de estructuras de datos no lineales.
Implementar árboles utilizando C++.
Aplicar recorridos DFS y BFS.
Identificar problemas de desbalance.
Implementar mecanismos de balanceo.
Seleccionar estructuras de datos adecuadas para resolver diferentes problemas.
Analizar el comportamiento de los algoritmos implementados.
